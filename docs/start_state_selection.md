# 開始状態の選び方（荷崩れを少し大きくした走行）

提出用の走行を、これまでより少しずれた荷崩れから始めるための選び方。
ロボットの成功・失敗では選ばない。荷崩れだけを物理計算した時点の状態で、次の条件を判定し、最初に満たした番号を使う。

この条件と対象の番号は、測定を始める前に `scripts/survey_start_shift.py` とその起動の引数で決めた（2026-10-30 14:55 頃）。
この文書は測定の開始後、結果を開く前に、その中身を書き出したものである。

## 条件

| 項目 | 定義 |
|---|---|
| 対象の荷 | 段階 S3 と同じ 2 段（3 × 4 × 2 = 24 箱）、品目 BEV-500x24 |
| 開始状態 | `run_mission.py` と同じ手順（中身の偏り `vary_load`、ラップの外れた段、待機の位置、1 秒の静止、輸送の揺れ）を終えた時点の真値の姿勢 |
| 基準の位置 | 各箱の輸送前の位置（積み付けた位置） |
| 上の段 | 輸送前の高さが、いちばん低い箱より 0.1 m を超えて高い箱（2 段では上の 12 箱） |
| ずれた・傾いた | `evaluation/truth.py` の分類。水平に 0.03 m を超えて動いたら「ずれた」、傾きが 15 度を超えたら「傾いた」 |
| 落ちた | 同じ分類の「床」（パレットの外で天面より低い）と「段から落ちた」（0.05 m を超えて下がった） |

満たす条件（すべて）:

1. 「床」と「段から落ちた」が 0 個（荷崩れは「若干」にとどめる）
2. 上の段の半数以上が「ずれた」か「傾いた」
3. 上の段の水平の移動の最大が 0.10 m 以上
4. 上の段の水平の移動の中央値が 0.04 m 以上

## 試す番号

乱数の番号 105 から 124 まで（20 個）を順に試す。104 はこれまでの走行との比較のために測る（選ぶ対象ではない）。
124 までに満たすものがなければ、その事実を残し、条件も範囲も広げずに、これまでの開始状態（104）の走行で提出する。

## 合否

選んだ番号で `run_mission.py --layers 2 --trace --record` を 1 回走らせ、これまでと同じ段階 S3 の判定（`stage_gate.py`）で判定する。判定の基準は変えない。
不合格でも結果は残し、止まった理由と未処理の数を示す。

## 残すもの

各番号の判定と開始時の姿勢（`artifacts/start_state_survey/seedNNN.json`）、選んだ番号、走行の記録（manifest にコードの版と設定の sha256）。
