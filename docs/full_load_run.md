# 通常の荷での走行と映像（2026-11-01 夜、走らせる前に固定）

目的：通常の箱数の荷を、ロボットが自分で判断して移していく様子を、省略なしで映す。

| 項目 | 値 |
|---|---|
| 荷 | 3 × 4 × 2 段＝24 箱、品目 BEV-500x24（段階 S3 と同じ） |
| 始まりの状態 | 番号 118。[start_state_selection.md](start_state_selection.md) の条件で、ロボットを動かす前に選んだもの（2026-10-30） |
| 機体 | 2026-10-31 の作り直しの版 |
| 判断 | `shinai_learned`、`models/cascade_v4_camera.json`（真上のカメラの見立てから学んだ崩れの予測）。取る順・見に行く場所・運ぶ経路は、ロボットが走行中に自分で決める |
| 走らせ方 | 1 回だけ、最後まで走らせる。結果で番号を選び直さない |
| 判定 | 段階 S3（`scripts/stage_gate.py`、基準は変えない） |
| 映像 | 走行の 4.0〜334.0 秒（5 分 30 秒）を 2 倍速・省略なしで描き直す。動画は 3 分以内に収める |

運ぶ経路は学習していない。ロボットの計画（幾何の計算）が、その場の見立てから決める。
