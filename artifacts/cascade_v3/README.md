# cascade_v3 の学習データ（用途を限ったもの）

- 作り方: `scripts/gen_cascade_data.py --split train|seen|unseen`（場面は番号 2000〜2399、unseen は 2000〜2120 の 60 個）
- 入力: シミュレーターの箱の正しい位置と向きに雑音（位置 1 cm・向き 1.5 度）を足して組んだ見立てから計算した特徴
- 教師: 箱を一つ作業場の外へ瞬時に移し、1.5 秒後にほかの箱が動いたか（水平 5 cm 超、または 10 cm 超の下がり）

使ってよい用途: 支えを取り除いたときの崩れの予測を学習し、幾何の規則と比べること。

示さないこと: 内蔵カメラの映像から荷の形を認識する学習、運ぶ経路の学習、吸着で持ち上げる動作そのものの崩れ。
詳しくは `docs/generalisation_plan.md` の追記（2026-10-31 夜）を参照。
